# 🤖 Ollama AI Web Opener

My first LLM project using Python and Ollama.

This project takes a user's command and opens websites like YouTube, Google, GitHub, and Kick.

## 🚀 Features

- 🌐 Open YouTube
- 🔎 Open Google
- 🎮 Open Kick
- 💻 Open GitHub
- 🤖 Uses Ollama with Gemma 3 1B
- 🐍 Built with Python

## 🛠️ Technologies

- Python
- Ollama
- Gemma 3 1B

## 📚 What I Learned

- Using Ollama with Python
- `ollama.chat()`
- `while` loops
- `if / elif`
- User input
- `webbrowser`
- Python virtual environments
